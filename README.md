# Leonida Map — carte interactive GTA VI (fan-made)

Site statique avec une carte interactive de l'État de Leonida, dans les couleurs coucher de soleil / néon de GTA VI.

## Fonctionnalités
- Carte SVG dessinée à la main : Vice City, Leonida Keys, Grassrivers, Port Gellhorn, Ambrosia, Mount Kalaga
- Zoom à la molette / au pincement, déplacement à la souris ou au doigt
- 40+ lieux classés par catégorie (planques, missions, magasins, activités, transports, points d'intérêt) avec filtres
- Recherche de lieux et de régions
- Double-clic pour poser un waypoint avec itinéraire et distance
- Responsive (mobile / desktop)

## Lancer
Aucune dépendance : ouvre `index.html` dans un navigateur, ou :

```bash
python3 -m http.server 8000
```

Pour le mettre en ligne : GitHub → Settings → Pages → déployer depuis la branche.

## Ajouter des lieux
Tout est dans `data.js` (coordonnées dans un repère 1000 × 1300). Astuce : le coin en bas à gauche de la carte affiche les coordonnées sous la souris.
